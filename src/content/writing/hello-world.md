## How posts work

Each post is a Markdown file. The front matter at the top sets the title, date,
description, and tags. Everything below it is the body, and it supports all the
usual Markdown:

- **Bold** and _italic_ text
- Lists, like this one
- [Links](https://example.com)
- Code blocks with syntax highlighting:

```ts
function greet(name: string) {
  return `Hello, ${name}`;
}
```

> Blockquotes look like this — handy for pulling out a line.

That's the whole system. No database, no CMS. Write, save, done.
